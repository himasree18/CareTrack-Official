# 🏥 CareTrack - Medicine Reminder System

## 📌 Overview
CareTrack is a web application that helps users manage medicine schedules and receive timely reminders.

## 🚀 Features
- ⏰ Set medicine reminders
- 🔔 Alarm notifications
- 📅 View history
- 💊 Manage medicines

## 🛠️ Tech Stack
- HTML, CSS, JavaScript
- Node.js

## ▶️ Run Locally
```bash
npm install
npm start
```

Create a `.env` file with your OpenAI key (needed for the Medicine Info page):

```
OPENAI_API_KEY=your-key-here
```

Then open http://localhost:3000 in your browser.

> Reminders are stored in your browser and fire while any CareTrack page is open.
